# 交付说明：quoting-prd-gap

## 依据
- PRD 截图：一站报价流程、基础信息、价格分区、报价明细、多选展开收起、地址选择

## 已补齐（P0）
1. **基础信息**：生效时间改为日期范围；计费策略默认「统计考核」，选项对齐「普通/统计考核/合单计费/统计+合单」；复杂报价默认折叠且带默认值；商家编码失焦校验回填。
2. **价格分区**：价格分区名称 / 报价申请单号 / 合同编码；始发地、目的地点击打开地址弹窗；可选维度多选 `collapse-tags`；费用项/订单类型/配送类型/正逆向随维度显隐；分区上限提示 10000。
3. **地址弹窗**：国内/跨境页签、大区多选、批量搜索（逗号/顿号/换行，上限 300）、层级勾选、已选汇总 +N 展开收起。
4. **报价明细**：统计对象（统计策略）、单票阶梯/累进、区间开闭、业务进位、轻抛系数；表列含统计上下限、阶梯上下限（阶梯模式≠无）、折扣模式、报价数值。
5. **场景强校验**：场景报价且勾选费用项维度时，须覆盖场景全部费用项；否则提示「报价不完整」并阻断下一步/提交。

## 范围
仅 `OnestopQuoting.vue` + `AddressEditorModal.vue` + `scenarioQuoteValidate.js` + `scenarioPricing.js`。未改 `global.css`。
