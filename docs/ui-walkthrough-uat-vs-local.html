1. 一站定价 - 列表

定价中心 → 一站定价

/cpq/onestop-pricing

视觉样式

  • UAT 左侧菜单可收起，不把大框架左侧菜单本身作为问题；但 UAT 内容区上、左、右间距均为 24px，叠加 Portal 顶部导航后，当前截图里页面整体视觉比例偏大、首屏可见内容偏少。
  • UAT 主内容可视宽度约 1016px，设计稿约 1336px，列表横向承载能力下降，表格列更容易拥挤。

功能数据

  • 筛选字段不一致：设计稿筛选项为「方案名称 / 业务场景 / 状态 / 创建人 / 创建时间」；UAT 增加「方案编码」，这是字段规则差异，需要确认是否回补到设计稿。
  • 表格列不一致：设计稿列为「方案名称 / 定价方式 / 业务场景 / 状态 / 创建人 / 创建时间 / 操作」；UAT 增加「方案编码 / 生效日期 / 失效日期」。

交互效果

  • 设计稿操作列包含「查看 / 编辑 / 启用 / 停用」的不同状态组合；UAT 当前可见操作为「查看 / 编辑」和「查看 / 停用」，操作状态规则需对齐。

5. 一站定价 - 编辑后点击下一步的阻断态

一站定价列表 → 编辑 → 下一步

/cpq/onestop-pricing → 编辑 → 下一步

视觉样式

  • 设计稿点击下一步后的必填错误为红色边框 +「请填写」，仍停留 Step1；UAT 点击下一步后同样停留 Step1，但在计费场景配置行内增加红框和底部橙色业务提示。

  • 点击「下一步」未进入定价规则步骤，流程被阻断；UAT 有明确业务提示，设计稿只有必填校验，两侧阻断反馈规则需统一。
