## 分页面问题摘要

### 1. 一站定价 — 列表
- **视觉**：状态 UAT 纯字 `#12B35D` vs 本地 Tag 胶囊
- **功能**：UAT 分页 total=0 有数据；缺方案编码筛/列；操作「失效」vs「编辑/启停」

### 2. 一站定价 — Step1
- **视觉**：步骤条 40px / 上下间距 24px 未达标；「设备场景配置」vs「计费场景配置」；配置表列不一致
- **功能**：label「有效期时间」文案

### 3. 日期选择
- **交互**：校验「请填写」12px `#FC3737` 距控件 4px

### 4. 设备条件弹窗
- **视觉**：弹窗圆角 8px；虚线新增按钮规格
- **交互**：遮罩 / 删除链 Hover `#3C6EF0→#2F5CD6`

### 5. 计费要素 — 列表
- **视觉**：标题「商品要素」vs「计费要素」；状态 Tag
- **功能**：「应用企业接入点」vs「按商家接入」；total 绑定

### 6. 计费要素 — 新建（多选）
- **视觉**：Tag 22px/14px/圆角4；**max-height 64px** 待加；下拉项 32px
- **交互**：禁 Tag tooltip；focus 描边 + 2px 光晕

### 7. 一站报价 — 列表
- **功能**：UAT total=0 有 2 行

### 8. 报价预览
- **视觉**：二级标题字号；只读 label `#868D9F`
- **功能**：复杂报价隐藏需 UAT 回归

### 9. 关闭确认
- **功能**：本地未实现 Tab 关闭拦截
- **交互**：次按钮「留在本页」

### 10–11. 报价 Step2/3
- **视觉**：步骤条同全局；完成勾 `#12B35D`；Step3 warning 色 `#FFFBE6/#FAAD14`

### 12. 业务场景弹窗
- **视觉**：校验/error 色；弹窗 padding 16×24
- **功能**：收付方向字段；「场景定价」vs「业务场景定价」
- **交互**：Select focus/hover 态

4. 文案/字段/操作与 UAT 产品稿对齐
